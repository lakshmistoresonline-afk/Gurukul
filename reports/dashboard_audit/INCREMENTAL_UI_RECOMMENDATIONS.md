# GURUKUL AI — INCREMENTAL UI RECOMMENDATIONS REPORT

This document presents low-risk, high-value incremental UI and interactivity refinements that preserve existing data bindings and components.

---

## Proposed Incremental Refinements

### Proposal 1: Animated Progress Ring on Subject Cards
- **Current Behavior**: Linear horizontal progress bar showing `% Mastered`.
- **Proposed Small Change**: Add a circular progress ring next to the realm title for enhanced visual feedback.
- **User Benefit**: High visual satisfaction for young learners tracking mastery.
- **Data/API Impact**: None.
- **Regression Risk**: Low.

### Proposal 2: Daily Quest Reset Countdown
- **Current Behavior**: Displays 3 daily missions.
- **Proposed Small Change**: Add a subtle countdown timer (`Resets in 8h 12m`) at the top right of the Daily Quests widget.
- **User Benefit**: Urgency and daily habit reinforcement.
- **Data/API Impact**: None.
- **Regression Risk**: Low.

### Proposal 3: Recent Activity Quick Thumbnail Preview
- **Current Behavior**: Resume banner shows textual chapter ID (`G5-ENG-U01-C01`).
- **Proposed Small Change**: Display the small chapter thumbnail illustration alongside the resume button.
- **User Benefit**: Instant visual recognition of the last studied lesson.
- **Data/API Impact**: None.
- **Regression Risk**: Low.
