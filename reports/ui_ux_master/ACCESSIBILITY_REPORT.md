# GURUKUL AI — ACCESSIBILITY REPORT
**Date**: November 3, 2026  

---

## 1. Accessibility Compliance Checklist

- **`aria-current`**: Active navigation links set `aria-current="page"`.
- **Accessible Button Names**: All icon-only buttons (`Sign Out`, `Close`, `Menu`, `Copy`, `Read`) feature explicit `aria-label` or `title` attributes.
- **Keyboard Navigation**: Input fields submit on `Enter`, insert newlines on `Shift+Enter`, interactive buttons navigable via `Tab`.
- **Contrast**: High-contrast dark typography (`text-slate-900`, `text-slate-800`) over light canvas (`#F4F6FA`).
